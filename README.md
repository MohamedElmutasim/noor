# 🕌 نور (Noor) - تطبيق إسلامي شامل ومرافق يومي ذكي
> **تطبيق إسلامي متكامل وحديث مبني باستخدام Flutter يهدف إلى تيسير العبادات اليومية، ومتابعة الختمة القرآنية، وضبط مواقيت الصلاة بدقة دون انقطاع.**

---

## 📖 عن المشروع (About)

في ظل تسارع الحياة اليومية وكثرة المشتتات الرقمية، يواجه الكثير من المسلمين صعوبة في تنظيم أورادهم اليومية والالتزام بمواقيت الصلاة ومتابعة ختمة القرآن الكريم بانتظام. جاء تطبيق **"نور"** ليكون رفيقاً إسلامياً يومياً يجمع بين جمال وبساطة التصميم وأحدث الممارسات البرمجية في بيئة **Flutter**.

يعتمد التطبيق على معمارية برمجية قائمة على الميزات (**Feature-First Architecture**) ونهج العمل دون اتصال أولاً (**Offline-First**)، حيث يقوم بحساب وجدولة مواقيت الصلاة وإشعارات الأذان استناداً إلى الموقع الجغرافي الدقيق وتخزينها محلياً، مع دعم التحديث الدوري والمزامنة التلقائية في الخلفية عبر مهام النظام المجدولة، ليكون حلاً تقنياً متكاملاً، سلساً، وموثوقاً في أي وقت وأي مكان.

---

## ✨ المميزات الرئيسية (Key Features)

- ⏱️ **مواقيت صلاة دقيقة مع عداد تنازلي حي:**
  - حساب أوقات الصلوات الخمس والشروق اعتماداً على إحداثيات GPS بدقة، وبحسب معيار الهيئة المصرية العامة للمساحة وAladhan API.
  - مؤقت لحظي يحسب الوقت المتبقي للصلاة القادمة تلقائياً.
  - دعم كامل للعمل بدون إنترنت (Offline-First) مع كاش شهري محلي متقدم.

- 📖 **المصحف الشريف والقرآن الكريم:**
  - فهرس كامل لـ 114 سورة قرآنية مع توضيح مكان النزول (مكية / مدنية) وعدد الآيات والترتيب.
  - وضع قراءة المصحف الشريف المصور المعتمد (604 صفحات) مع تقليب صفحات سلس ومرن.
  - حفظ العلامات المرجعية (Bookmarks) تلقائياً للعودة السريعة لآخر صفحة تمت قراءتها.
  - محرك بحث فوري وسريع للوصول إلى أي سورة بالاسم العربي أو الإنجليزي أو الرقم.

- 🎯 **متابعة الختمة الذكية (Quran Khatmah Tracker):**
  - تتبع تقدم الختمة القرآنية صفحة بصفحة وحساب النسبة المئوية للإنجاز بدقة.
  - تحديد الفترة الزمنية المستهدفة (مثلاً 30 يوماً) وحساب الورد القرآني اليومي المقترح تلقائياً.
  - إمكانية بدء ختمة جديدة وإعادة الضبط بنقرة زر واحدة مع توثيق تاريخ آخر قراءة.

- 🎧 **تلاوات قرآنية واستماع بدون إنترنت:**
  - مشغل صوتي مدمج لتلاوة القرآن الكريم بصوت القارئ مشاري راشد العفاسي.
  - إمكانية تحميل السور وتخزينها على ذاكرة الهاتف للاستماع إليها دون الحاجة للاتصال بالإنترنت.
  - تحكم كامل بالصوت: تشغيل، إيقاف مؤقت، تقديم، تأخير، شريط تمرير زمني لحظي، وتكرار.

- 📿 **حصن المسلم والأذكار اليومية:**
  - أذكار الصباح والمساء كاملة مع الفضائل والسند الشرعي الصحيح.
  - عداد تفاعلي مستقل لكل ذكر مع اهتزازات لمسية خفيفة (Haptic Feedback) لإشعار المستخدم بانتهاء التكرار.
  - شريط تقدم ذكي يوضح نسبة ما تم إنجازه من الأذكار.

- 🟢 **السبحة الإلكترونية المتطورة:**
  - عداد تسبيح رقمي مع تأثيرات حركية نابضة وتجاوب لمسي عند الضغط.
  - تنبيه اهتزازي خاص ومميز عند إتمام دورة التسبيح (33 تسبيحة).
  - قائمة مدمجة بأشهر صيغ الذكر والاستغفار، مع حفظ إجمالي عدد التسبيحات التراكمي محلياً.

- 🧭 **بوصلة القبلة التفاعلية (Real-time Qibla Compass):**
  - تحديد اتجاه القبلة بدقة اعتماداً على مستشعرات البوصلة المغناطيسية والجيروسكوب في الجهاز.
  - تنبيه بالاهتزاز وتأثير بصري فوري عند محاذاة الهاتف تماماً مع زاوية الكعبة المشرفة (دقة ±4 درجات).

- 🌙 **إمساكية شهر رمضان المبارك:**
  - جدول تفصيلي كامل لأيام شهر رمضان مع مواقيت الإمساك والإفطار والصلوات.
  - تمييز آلي لليوم الحالي من الشهر الفضيل، مع عرض التاريخين الهجري والميلادي.

- 📱 **ودجتس الشاشة الرئيسية (Home Screen Widgets):**
  - ودجت لمواقيت الصلاة وموعد الصلاة القادمة مباشرة على شاشة الهاتف الرئيسية.
  - ودجت يومي يعرض اسماً من أسماء الله الحسنى الـ 99 مع ترقيبه ومعناه.

- 🔔 **نظام تنبيهات متطور وخلفية مستقرة:**
  - تنبيهات الأذان والتذكيرات الروحية (أذكار الصباح 7:00 ص، أذكار المساء 5:00 م، سنن الجمعة 9:00 ص، والورد القرآني).
  - استخدام مكتبة `WorkManager` لجدولة مهام دورية في الخلفية تعمل كل 12 ساعة لتحديث الكاش والودجتس بدون استهلاك للبطارية.
  - معالجة دقيقة للمنبهات الدقيقة (Exact Alarms) واستثناءات ترشيد البطارية (Battery Optimization).

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المجال | التقنية المستخدمة |
| :--- | :--- |
| **إطار العمل واللغة** | Flutter (Dart SDK ^3.13.2) |
| **إدارة الحالة (State Management)** | Provider (`MultiProvider`, `ChangeNotifier`) |
| **معمارية المشروع** | Feature-First / Modular Clean Architecture |
| **التخزين المحلي والكاش** | `shared_preferences`, `path_provider` |
| **الاتصال بالشبكة (Networking)** | `dio` (مع معالجة الأخطاء والـ Timeouts) |
| **واجهات البيانات الخارجية (APIs)** | [Aladhan API](https://aladhan.com/prayer-times-api) (المواقيت والقبلة والتقويم)، [MP3Quran](https://mp3quran.net) (التلاوات الصوتية) |
| **تشغيل الصوتيات** | `audioplayers` |
| **المهام في الخلفية** | `workmanager` (Background Periodic Tasks) |
| **الإشعارات والمنبهات** | `flutter_local_notifications`, `timezone`, `flutter_timezone` |
| **الموقع والمستشعرات** | `geolocator`, `geocoding`, `flutter_compass`, `vibration` |
| **الحسابات الإسلامية** | `adhan`, `quran`, `hijri` |
| **عناصر الواجهة والودجتس** | `home_widget`, `google_fonts`, `cupertino_icons` |

## 🚀 طريقة التشغيل (How to Run Locally)

لتشغيل المشروع محلياً على جهازك، تأكد أولاً من تثبيت متطلبات بيئة Flutter:

### المتطلبات المسبقة:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.13.2 أو أحدث).
- [Dart SDK](https://dart.dev/get-dart).
- بيئة تطوير متكاملة: [VS Code](https://code.visualstudio.com/) أو [Android Studio](https://developer.android.com/studio).
- محاكي أندرويد/iOS أو هاتف حقيقي موصول بالكمبيوتر ومفعل عليه وضع تصحيح الأخطاء (USB Debugging).

### خطوات التثبيت والتشغيل:

1. **استنساخ المستودع (Clone the Repository):**
   ```bash
   git clone https://github.com/your-username/noor.git
   cd noor
   ```

2. **تثبيت الحزم والمكتبات (Get Dependencies):**
   ```bash
   flutter pub get
   ```

3. **التحقق من سلامة الأكواد (Code Analysis):**
   ```bash
   dart analyze lib
   ```

4. **تشغيل التطبيق (Run Application):**
   ```bash
   flutter run
   ```

> **ملاحظة:** لتجربة ميزات المستشعرات مثل بوصلة القبلة وودجتس الشاشة الرئيسية وتنبيهات الأذان الصوتية بدقة كاملة، يُفضل دائماً تشغيل التطبيق على هاتف حقيقي (Real Device).
